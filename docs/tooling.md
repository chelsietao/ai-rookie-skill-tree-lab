# Editor and version-control practice

- VS Code: open the repository root, select `.venv`, and run tasks from the integrated terminal.
- Jupyter/Colab: notebooks are thin tutorials backed by tested modules under `src/`.
- vi: `vi README.md`, `:w`, and `:q` cover the official beginner editor requirement.
- Git: use feature branches, focused commits, annotated release tags, and `.gitignore`.
- GitHub: Actions run lint, tests, data smoke checks, and MySQL integration.
- GitLab: `.gitlab-ci.yml` mirrors the portable lint/test job; no GitLab account is required.
