# GitHub gap analysis

Before this lab, the public portfolio already contained:

- NumPy, Pandas, Matplotlib, Jupyter, and a from-scratch perceptron in `Penguin_classifier`.
- PyTorch MLP and automatic differentiation in `pinn-laplace-complex-analysis`.
- Scikit-learn, StandardScaler, Random Forest, XGBoost, and Seaborn in `vocal-age-analyzer`.
- PyTorch/Transformers model analysis in `LLM-Refusal-Mechanism-Exploration`.
- Logistic/Ridge models, a custom CNN, ViT, JSON/YAML, and CI in `multimodal-finance-agent-research`.

The evidence audit found weak or absent coverage for TensorFlow/Keras/TensorBoard; KNN, SVC/SVR,
Lasso, Decision Tree, Extra-Trees, CatBoost; RNN/LSTM/GRU; autoencoders; GNN; standard CNN families;
object detection; clustering/dimension reduction; formal ablations; AutoML; MySQL/MSSQL; and GitLab.

This repository fills those gaps in one coherent experiment system rather than modifying the older
repositories or duplicating their application stories.
